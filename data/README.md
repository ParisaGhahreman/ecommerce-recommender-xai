# Data Directory

This directory is intentionally excluded from the public repository except for this documentation file.

## Expected structure

```text
data/
├── raw/
│   ├── events.csv
│   ├── category_tree.csv
│   └── yoochoose/
│       ├── dataset-README.txt
│       ├── yoochoose-clicks.dat
│       ├── yoochoose-buys.dat
│       └── yoochoose-test.dat
│
└── processed/
    └── Files generated automatically by the notebooks

```
Notes
Raw source datasets are not included because of file size and dataset-specific license terms.
Processed files are generated by running the notebooks in sequence.
Download instructions, original dataset sources, and license notes are available in ../DATA_SOURCES.md.
The .gitignore file excludes data/raw/ and data/processed/ from GitHub
